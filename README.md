### 《执炬》· 少年热血爽文（三部+番外完结 · 25章+4番外 · 约10万字）

> 九州大地，人人以心火修行。青岚城少年林小满，天生琉璃火，十岁被嫡系堂兄一掌夺走，沦为"灰人"，被当牲口使唤六年。
>
> 十六岁雪夜，断剑吊坠里传出声音："小子，想不想把火拿回来？"
>
> 夺我火者，我必讨回。欺我亲者，我必踏平。深渊压境，我执炬而行。
>
> 第一部：火会被抢走，但点燃火的手，夺不走。
> 第二部：疼是柴，愿才是火。
> 第三部：真正的传承，是每一代人都往那盏火里，加自己的一根柴。
