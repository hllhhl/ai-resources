>
> 十六岁雪夜，断剑吊坠里传出声音："小子，想不想把火拿回来？"

> 夺我火者，我必讨回。欺我亲者，我必踏平。深渊压境，我执炬而行。
>
> 火会被抢走，但点燃火的手，夺不走。
