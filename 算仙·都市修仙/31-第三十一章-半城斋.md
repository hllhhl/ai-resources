# 第三十一章 半城斋

雨夜，半城斋，正门大开。

没有门童，没有护卫。一个穿旗袍的女子立在门内，朝陆离微微一躬："陆先生，我家先生已候您多时。"

季白在陆离身后，喉结滚了滚："先生，我……"

"你在门外。"陆离把伞递给他，"看住大门。我给你一个时辰——一个时辰我还没出来，你去街角电话亭，打给这个号码。"

他塞给季白一张字条，然后整整衣领，独自跨进了门槛。

门在身后合上。

斋内别有洞天。穿过前厅，是一方天井，雨丝从檐角落下，在青石板上敲出细密的声响。天井往里，一进、两进、三进，灯火层层叠叠，深处传来若有若无的琴声。

陆离走得不快，边走边看。

这半城斋的结构，不对。

不是"宅子"的结构，是"器"的结构。天井为"窍"，回廊为"络"，七进院落环环相扣，暗合周天。每走一步，他袖中的天机盘就沉一分——这整栋建筑，是一座"阵"，一件"活的法器"。

而他，正走在"器"的肚子里。

最里一进，正堂。

堂上无灯，只点着四盏白蜡烛。八仙桌摆着一副残棋，一壶酒，三只杯。

上首坐着的，正是白日里那位灰长衫老者。

下首，还空着一个位子。

"陆先生。"老者抬手，"请。"

陆离在空位上坐下，先开了口："先生高姓？"

"姓氏这种东西，我这把年纪，早就不讲究了。"老者执壶斟酒，"你可以叫我，'半城'。"

"沈阳城一半的产业，挂在我名下。"他笑了笑，"半城之名，俗气，但贴切。"

"林薇薇呢？"陆离问。

"薇薇是晚辈，没资格上桌。"半城朝侧门抬了抬下巴，"她在帘子后面，替我记着账。"

陆离不用看也知道，那道帘后，林薇薇正竖着耳朵，听堂中一字一句。

"说吧。"半城把酒杯推过来，"陆先生远道而来，是兴师问罪，还是投诚纳名？"

"都不是。"陆离没碰酒，"我来对账。"

老者执杯的手，几不可察地顿了一下。

"对账？"

"半城先生，我给你算算。"陆离伸出一根手指，"你借白家商队，给我递了句狠话——这一笔，惊扰。"

第二根手指："你在江州放'老大'扫城找盘，三桩案子，惊了九处的局——这一笔，扰序。"

第三根手指："你的人林薇薇，在我这儿请我看了一面'真货'铜镜，想借我的眼替'缝'收器——这一笔，算计。"

他抬起眼，看着半城：

"三笔账，账账我都记着。今日登门，不为翻脸——"

"为的是当面告诉你：**往后，我的账，你别碰。**"

烛火摇了摇。

半城盯着他看了很久，忽然笑了，笑得咳呛起来："好胆色！练气三层，敢跟我筑基后期的'东西'，坐一张桌子上讲条件。"

"你知道我一只手，能捏死你几个？"

"知道。"陆离说，"一个。就一个。"

"你捏死我，'缝'后那位交给你的差事，就烂在沈阳了。找不回盘，交不了差——你自己说的，跑腿的上面得有管事的。管事的办砸了差，是个什么下场，先生比我清楚。"

半城的笑，一寸寸敛了。

堂中安静得能听见烛芯的哔剥声。

"你拿话套我。"老者缓缓道，"想诈出'缝'后那位，待我如何。"

"不是诈。"陆离终于端起了酒杯，抿了一口，"是给你递个台阶。"

"先生，你我都知道，你不想办这个差。"他放下杯子，"一个在人间扎根百年的'老东西'，产业、身份、日子都过顺了——'缝'后那位忽然要你收盘、下锚、清理门户。这差事，办好了，你还是奴才；办砸了，你是死奴才。"

"我说得对吗？"

烛光里，半城长久地沉默着。

半晌，他忽然抬手，朝帘子后面，轻轻一挥。

帘后传来一声极轻的、布料摩擦的响动——林薇薇，退下了。

堂中只剩两人。

"陆先生。"半城的声音，第一次低了下来，"你想说什么，直说吧。"

"我想说的是——"陆离身体微微前倾，一字一字：

"差事，可以办砸。"

"账，可以记在别处。"

"我给你一个机会——从'缝'的奴才，改换成我的债主名单上的，**盟友**。"

"你——敢不敢换这个主子？"

（第三十一章 完）
